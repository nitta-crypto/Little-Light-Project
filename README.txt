LITTLE LIGHT PROJECT — CURSIVE WEBSITE PACK

1. Extract this ZIP into a NEW folder first, so your existing website stays safe.
2. Open that extracted folder in VS Code.
3. Right-click index.html and choose Open with Live Server.
4. Dancing Script is used for the logo, headings, and director signature. Poppins is used for body text so it stays readable.
5. Replace image paths with your own downloaded picture filenames.

DIRECTOR PHOTO:
In about.html, find:
<img class="director-photo" src="images/director.jpg" alt="Photo of the founder and director">
Put your photo in the images folder and name it director.jpg, OR change images/director.jpg to your exact filename.
The photo code is already there.

PICTURES:
This pack intentionally has image placeholders. Change each src="images/..." to the exact filename you have. Keep the images inside the images folder. Match uppercase/lowercase and file extensions exactly.
If a photo is named community6.JPG, for example, use src="images/community6.JPG".

FONT:
Dancing Script and Poppins load from Google Fonts, so the first preview needs internet access.
